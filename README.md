# Pretty Colours Face Paint

Simple static one-page site for a face painting events business, styled with [Tailwind CSS](https://tailwindcss.com) (via CDN, no build step) and a contact form powered by [Static Forms](https://staticforms.dev).

## Setup

1. Sign up at https://staticforms.dev and create a form to get an API key.
2. In `index.html`, replace `YOUR_STATICFORMS_API_KEY` (in the hidden `apiKey` input) with your real key.
3. Replace placeholder text, gallery photos, and footer year with real content.

## Running locally

Just open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploying

This is a static site — deploy the folder as-is to GitHub Pages, Netlify, Vercel, etc.
